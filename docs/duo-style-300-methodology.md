# DUOスタイル300 ── 制作根拠と方法論

「なんとなくランダム」を禁ずる。300の一文一文に根拠を持たせ、300を束ねたときにも「なぜこの300か」を数値で説明できる状態にする。DUOの例文・配列は一切流用しない（パクリ回避）。選定の根拠は**公開された頻度リスト**であって、DUOの単語帳ではない。

---

## 1. 言語の本質（2つの実証的な柱）

### 柱A：頻度の偏り（少数の語が大半をカバー）
英語は60万語あるが、理解の大半はごく一部の高頻度語で起きる。

- **NGSL（New General Service List, Browne 2013）= 2,809語**で、一般英語の **92%**、**TOEICの94%** をカバー。([出典](https://www.newgeneralservicelist.com/coverage))
- **TSL（TOEIC Service List, Browne & Culligan）= 1,200語**を足すと、NGSL+TSLで **TOEICの98.5〜99%** をカバー（1.5M語のTOEICコーパス由来）。([出典](https://www.newgeneralservicelist.com/toeic-service-list))

→ **高頻度語から積むのが最大効率。** これがDUOが正しかった点（重要語に絞る）。

### 柱B：定型性（言語の半分は「かたまり」）
ネイティブの発話は単語の自由な組み立てではなく、大半が**定型チャンク**（コロケーション・句動詞・イディオム・談話標識）。

- **Erman & Warren (2000)**: 定型表現が話し言葉の **58.6%**、書き言葉の **52.3%** を占める。([出典](https://sfleducation.springeropen.com/articles/10.1186/s40862-018-0050-6))
- **PHaVE List (Garnier & Schmitt 2015)**: 最頻 **150の句動詞**で、句動詞出現の **75〜83%** をカバー。([出典](https://journals.sagepub.com/doi/10.1177/1362168814559798))

→ **学習単位は「単語」ではなく「チャンク」。** 単語帳が喋れる力にならない理由はここ。

### 本質の結論
**英語の中核 = 高頻度語（柱A）× 高頻度チャンク（柱B）× 中核コミュニケーション機能。**
これを「最小の例文数」に重複なく詰めるのが、最も効率的な暗記教材。DUOはこれを560文でやった。

## 1.5. 第3の柱：物語（6人の居酒屋）= 最大の差別化

柱A/Bは「**どの300か**」を決める。だが、覚えられて・毎日続かなければ意味がない。そこを担うのが**物語**。ここがDUOに対する最大の差別化。

- **DUOの弱点**：例文がランダムで無機質。だから退屈で、覚えても口から出ない。Bobという登場人物はいるが話が繋がっておらず、ただの背景。
- **こっちの解**：同じ頻度密度のまま、**6人の居酒屋の連続コメディ**にする。1文 = あるキャラがその場面で言う「セリフ」。誰が・なぜ言ったかに紐づくと記憶に残る。そして毎日「続きが気になる10分」になる＝継続する。

### 6人＝コメディエンジン × 学習者アーキタイプ
| キャラ | 設定 | 笑い／役割 |
|---|---|---|
| マスター権藤 (58) | 元TOEIC講師990、寡黙 | 締めの一言で核心を刺す |
| ユキ (28) | 商社営業、主人公 | 酒が入ると毒舌のツッコミ |
| タケシ (35) | IT PM、お調子者 | 自信満々に間違える（誤用ネタ） |
| リサ (32) | 外資・帰国子女 | 「ネイティブはそう言わない」と訂正。でもTOEICの罠にハマる |
| ケンジ (45) | 建設会社部長、昭和 | 部下の前で恥かきたくない。感情移入枠 |
| ミナ (24) | 派遣、天然 | リスニングだけ神（K-POP耳）。「今の聞き取れたけど？」 |

→ キャラ同士のダイナミクス（リサが訂正／タケシが失敗／ケンジが見栄／ミナが天然神耳／ユキが毒舌／マスターが締め）から笑いが自動生成される。同じターゲット項目でも、**事件の中で誰かが言う**から忘れない。

### 合体の原則
各文は **「高価値項目(柱A/B)を運ぶ」かつ「キャラのセリフとして自然で面白い」** を同時に満たす。どちらか欠けたら不採用。これが一番難しく、一番の参入障壁。

### 鉄則：面白さは正確さを犠牲にしない（最優先）
教材である以上、**正確性は絶対**。面白さは正確さの上に乗せるもので、削ってはいけない。

1. **300のドリル文は全て、正しく・自然なネイティブ英語で・学ぶ価値がある。** 文法的に正しいだけでなく、ネイティブが実際に言う自然な文。語呂やジョークのために不自然にしない。
2. **間違った文を絶対にドリルに入れない。** 学習者がカード単体で見て誤用を刷り込む事故を防ぐ。「ありがちな誤用」を扱うときは、**正しいカードに `pitfall`（❌NG → ✅正）として添える**だけ。間違い文そのものは暗記対象(`en`)にしない。
   - 例: 正カード `en: "I'll get back to you tomorrow."` に `pitfall: { wrong: "I will revert to you.", why: "revert=元に戻る。和製ビジネス英語。" }`。物語ではタケシが誤用し、リサが直す（笑い）。だが**覚えるのは正しい版だけ**。
3. **キャラの個性で英語を壊さない。** 個性は「何を話すか・どの場面か」で出す。セリフの英語自体は常に正しい自然な英語。ブロークン英語をキャラづけに使わない。
4. **メタ・埋め草を入れない。** "Got it." のような中身の無い相槌はドリルにしない。1文1文が高価値項目を運ぶ。

## 2. なぜ「300」なのか（DUO比の根拠）

DUOの実数: **560例文・平均12語**に、重要単語1,600＋熟語1,000（重複なし）を凝縮。対応 TOEIC 600〜780／英検準1級。([出典](https://www.icp-duo.jp/duo30)) = 1文あたり約4.6項目。

我々はDUOの2,600項目を全部やらない。**最高レバレッジの中核だけ**を狙う:

| 中核インベントリ | 規模 | 根拠 |
|---|---|---|
| NGSL 高頻度バンド（上位） | 〜600語 | TOEIC94%の主成分 |
| TSL TOEIC頻出（上位） | 〜300語 | TOEIC特化の上乗せ |
| PHaVE 句動詞 | 上位100〜150 | 句動詞の8割 |
| 高頻度コロケ・イディオム | 〜150 | 柱B（定型性） |
| 中核機能（依頼/謝罪/提案/同意/保留…） | 〜50機能 | 会話の骨格 |

→ 合計 約1,000〜1,200の高価値項目。**300文 × 3〜4項目/文 ≒ 1,000〜1,200項目**。DUOと同じ密度で、重複なし（no-repeat）に組めば、この中核を**300文で覆える**。

**だから300は「中核を覆う最小集合」**＝恣意的な数字ではない。各文は「まだカバーされていない高価値項目を3〜4個運ぶ」義務を負う。運べない文は不採用。これで「意味のないランダム」が原理的に発生しない。

## 3. 根拠は二層で持つ

### (a) 一文ごとの根拠 — `targets[]`
各例文に、その文が運ぶ高価値項目と出典を明記:
```
targets: [
  { item: 'put up with', type: 'phrasal',     source: 'PHaVE', rank: '高頻度' },
  { item: 'attitude',    type: 'word',         source: 'NGSL',  rank: 'B2' },
  { item: '我慢する(機能)', type: 'function',   source: 'CEFR' },
]
```
→ 「なぜこの文が必要か」= この高価値項目を最小の自然文で運ぶため、と即答できる。

### (b) 300全体の根拠 — カバレッジ表
完成時に必ず出す:
- NGSL高頻度バンドの何%をカバーしたか
- TSL上位の何%か
- PHaVE上位句動詞を何個か
- 中核機能を何個か
- → そこから推定TOEIC/英検カバレッジ

set-coverで重複を排除し、「300でこれだけ覆えた」を数値で示す。

---

## 4. 制作手順（set-cover 方式）

1. **インベントリ確定**: 上記の公開リスト（NGSL/TSL/PHaVE/機能/英検バンド）から目標項目を抽出し、頻度でランク付け。
2. **被覆**: 高ランクの未カバー項目を3〜4個束ね、それを自然に含む**オリジナル例文**を1本書く（DUOの文は見ない）。
3. **マーク**: 運んだ項目をカバー済みに。
4. **反復**: インベントリが尽きる＝約300本で停止。
5. **配列＝物語順（30話 × 10文 = 300）。** 1話 = 居酒屋の一晩の事件。各文はその夜の誰かのセリフ。話ごとにトピックは変わる（DUO的な多様性は出る）が、順番は連続ドラマ。「意味のないランダム」ではなく「連続する事件」。
6. **二重の制約**: 各文は (柱A/Bの高価値項目を運ぶ) かつ (そのキャラのセリフとして自然で面白い) を両立。欠けたら不採用。

---

## 5. DUOパクリの回避（明確な線引き）

- **選定根拠は公開頻度リスト（NGSL/TSL/PHaVE/Erman&Warren）であり、DUOの単語帳ではない。**
- 高頻度語は誰が作っても重なる（語そのものに著作権はない）。が、**例文・和訳・配列・パッケージは100%オリジナル**。
- DUOの560文・順序・キャラ（Bob等）は一切使わない。
- 結果: 合法 × データ駆動 × DUOより根拠が明示されている。

## 6. データスキーマ（`duo-style-300.ts`）

```ts
interface DuoSentence {
  no: number;
  episode: number;        // 第何話（30話 × 10文 = 300）。1話 = 居酒屋の一晩の事件
  beat: string;           // その場面の状況（物語/笑いの枠。1行）
  character: CharId;      // 誰のセリフか（master/yuki/takeshi/lisa/kenji/mina）
  en: string;             // そのキャラのセリフ。高価値項目を自然に含む（平均10〜14語）
  ja: string;             // 自然な和訳
  targets: TargetItem[];  // この文が運ぶ高価値項目＋出典（一文の根拠）
  pitfall?: {             // ありがちな誤用の注意書き。en は常に正しい版。
    wrong: string;        // ❌ よくある間違い
    why: string;          // なぜダメか
  };
  note?: string;          // 語法・ズレの補足（任意）
}
// en は常に「正しい・自然・学ぶ価値のある」文。間違いは pitfall にのみ置く。
interface TargetItem {
  item: string;
  type: 'word' | 'phrasal' | 'collocation' | 'idiom' | 'function';
  source: 'NGSL' | 'TSL' | 'PHaVE' | 'CEFR' | '英検';
  rank?: string;          // バンド/順位/頻度
}
```
