## 0. コンセプト（一行）

**「TOEIC・英検に効く300フレーズ」を、居酒屋の常連たちが繰り広げる連続コメディの中で、本物の音声付きで覚える。** 1日10個・30日で一周・毎月回す。

入口は試験（検索需要が桁違い）。中身は「実際に喋れる英語」。お前自身が言う通り**スコアは影、本体は"その場で英語で回せるか"**。

## 1. なぜDUOに勝てるのか（肝）

DUOの正体と弱点を直視する。

| | DUO 3.0 | 居酒屋300 |
|---|---|---|
| 文の作り | **単語を詰めるための文**（vocab vehicle）。だから不自然 | **実際に職場で言うチャンク**を選ぶ。phrase-first |
| レジスター | 1つ（中立・教科書） | **4つ**: Core(試験○) / Vibe(リアル) / Scene(その場) / **Back(相手の返し)** |
| 物語 | Bobの浮気劇。断片的で続かない | **居酒屋の連続劇**。キャラに人生と職業がある |
| 音声 | スタジオ録音1本 | **YouGlishで実ネイティブが無限**（映画・動画） |
| 文化注釈 | なし | **日本語↔英語のズレを刺すcontext注釈**（最大の差） |
| 試験との接続 | なし | **TOEIC Part/英検級タグ**。ユキの口癖で笑いとして届く |
| 退屈さ | 棒読み・古いアメリカンジョーク | **日本の社会人あるある**で笑える |

**勝ち筋の本質 = 既存資産の掛け算:**
連続劇（記憶に残る）× 実チャンク（役に立つ）× 実音声（phrase.me級）× 試験タグ（信頼）× 4レジスター（深さ）× ゲーム儀式（続く）。

DUOは「死んだ本」。こっちは「生きてる箱」。

## 3. 1エントリの作り方（レシピ）

型は `MasterExpression`。1フレーズ = 次の全部を埋める:

1. **`japanese`** — 日本語の「言いたいこと」1つ
2. **`english[4]`** — 同じ意図を4レジスターで
   - **Core**: 試験で○がもらえる安全形（教科書）
   - **Vibe**: ネイティブのリアル口語
   - **Scene**: その状況の生々しい一言（前置き・感情込み）
   - **Back**: **相手の自然な返し**（会話として閉じる ← DUOに無い）
3. **`jaTranslations[4]`** — 各レベルの和訳
4. **`context`** — 日本語↔英語のズレを刺す注釈＋ひとネタ（**ここが価値の核**）
5. **`character`** — 誰が言うか（連続劇の一員として）
6. **`category`** — `work`(仕事) を新設済み。他は greeting/order/feeling/social...
7. **`exam`** — `{ toeic?: 'Part 3', eiken?: '2級' }`（任意）
8. **`youglish`** — 実音声を引くためのクエリ文字列（任意）

**フレーズ選定の鉄則:** 「実際に言う × 高頻度 × TOEIC/英検にも出る」の三重丸だけ採用。単語のために文を曲げない。`sample-day-business.ts` が全部満たした実例。

## 4. 300の構造

**300 = 30日 × 10フレーズ／日。1日10個覚えて、30日で一周、毎月まわす。**（既存 `daySlot`＋`month` がそのまま使える）

1日 = 1つの連続シーン（10個が1本の小芝居になる）。例: sample = 「仕事の電話が鳴り止まない夜」。

### 試験カバレッジ（汎用×両対応の設計）
旅行英語に寄りすぎない。30日を機能で配分（案）:

| ブロック | 日数 | 内容 | 試験の効き所 |
|---|---|---|---|
| 仕事の基本 | Day1-8 | 電話/メール/依頼/日程/報連相 | TOEIC Part2-4 中核 |
| 会議・交渉 | Day9-14 | 提案/同意/反対/保留/確認 | TOEIC Part3 / 英検2級 |
| トラブル対応 | Day15-19 | 謝罪/遅延/言い訳/フォロー | TOEIC Part2-4 |
| 雑談・関係構築 | Day20-24 | スモールトーク/誘い/断り | 英検2級面接 / TOEIC |
| 意見・議論 | Day25-30 | 賛否/理由/比較/まとめ | **英検準1級・2級ライティング/面接** |

→ TOEIC偏重にせず後半で英検の「意見を述べる」を厚くすることで**両対応**が嘘にならない。

### 毎月の回し方
- 月1周で300を1巡（新規10/日）。
- 2周目以降は「新規」ではなく**300を回す＋各フレーズのYouGlish実音声で耳を鍛える**（お前の本丸 degraded listening に接続）。
- 既存のストリーク/クエスト/フォージがリピートのゲーム性を担保。SRSは作り込まない（シンプルさが武器）。

## 5. 音声（phrase.me級）の実装

現状 `DailyConversationPlayer` は `speechSynthesis`（ブラウザTTS＝棒読み）。これが最大の弱点。

→ 各フレーズに **`youglish` クエリ**を持たせ、**既存のYouGlish統合を再利用**して実YouTube音声を連発。
- **新規コンポーネントは作らない。** YouGlishはこのリポで既に解決済み: `phrases-v2/page.tsx`・`TrainingClient.tsx` が `window.YG.Widget(...)` + `widget.fetch(query,'english')` を inline で実装している。kaiwaカードに同じパターンを移植するだけ。
- **注意（既出バグ）**: `Window.YG` をファイルごとに再宣言すると `YG:` vs `YG?:` の修飾子衝突が起きる（journalに記録あり）。**新たに `declare global` しない**。既存のグローバル型をそのまま使う。
- YouGlish公式ウィジェットで合法・無料・無限。
- 4レベルの読み上げはTTSを保険で残す。「正解の型」はTTS、「本物の音」はYouGlish、の二段構え。
- これが「フレーズ集」を「武器」に変える一手。
